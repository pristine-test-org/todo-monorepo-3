Board tips

Keep each card to one small job, and move it to Done the moment it is finished, so the board always shows what is really left.

  • Write short cards

    One line is enough. If a card needs a paragraph, split it into two cards.

    Cards over a line long are harder to scan.

  • Clear the Done column

    Remove finished cards at the end of the week and start the next one fresh.

    A short Done column feels good to look at.
